# RGB_0bx1100_VHDL

Proyecto de Sistemas Electrónicos Digitales, UPM (ETSIDI), curso 2026-2027.

## Cómo se juega

1. Se pulsa el botón de inicio y se genera un color RGB aleatorio.
2. El color aparece en el monitor durante unos segundos para que el jugador lo memorice.
3. Cuando desaparece, el jugador debe intentar reproducirlo utilizando los switches de la placa Nexys 7 (máximo 16 niveles por componente).
4. Al finalizar el tiempo, se compara el color original con el seleccionado y se muestra el porcentaje de acierto.

## Materiales

- Placa FPGA Nexys 7
- Monitor de ordenador
- Cable VGA
